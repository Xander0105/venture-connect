# VentureConnect India

A private networking hub for venture-backed company formation, bridging the communication gap in India's investment ecosystem.

## 🚀 Features

- **Multi-User Roles**: Tailored dashboards for Entrepreneurs, Investors, Bankers, and Business Advisors
- **Proposal Management**: Create, track, and manage business proposals with rich media support
- **Intelligent Matching**: Advanced filtering to connect investors with the right opportunities
- **Communication Hub**: Real-time messaging and secure document sharing
- **Financial Products**: Bankers can showcase their loan products and services
- **Consultation Services**: Business advisors can offer expertise to entrepreneurs

## 🛠️ Tech Stack

- **Frontend**: React 18, Tailwind CSS
- **Backend**: Firebase (Authentication, Firestore)
- **Deployment**: Firebase Hosting
- **Development**: Node.js, npm
